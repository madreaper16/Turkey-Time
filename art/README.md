# Artwork sources

Source and export images for Turkey Time!, maintained by **MadReaper16**.

- `whole-turkey`: raw and cooked inventory artwork.
- `turkey-egg`: turkey egg artwork.
- `branding`: male-model reference, project-icon master, and icon exports.

See `docs/ASSET_MANIFEST.md` for authoring scripts and `docs/CREDITS.md` for
project acknowledgments. These source images are not runtime dependencies.
