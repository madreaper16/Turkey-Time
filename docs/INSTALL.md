# Installation

1. Use Minecraft Java **26.3** and Java **25**.
2. Install Fabric Loader **0.20.1 or newer** and Fabric API
   **0.165.0+26.3 or newer for Minecraft 26.3**.
3. Put the Turkey Time runtime JAR and Fabric API JAR in the instance's `mods` directory.
4. Install the same Turkey Time version on the client and server for multiplayer.
5. Remove older Turkey Time JARs when updating. Do not install the sources JAR as a second mod.

The gameplay suite passes with Fabric API 0.165.0+26.3 and 0.165.2+26.3.
Turkey Time does not require an upgrade to 0.165.2.

The mod creates `config/turkeytime.json` on first launch. Restart after changing
settings. See [configuration](CONFIG.md) and [known limitations](KNOWN_ISSUES.md).
Back up existing worlds before updating mods.

## Thanksgiving Feast

Use a crafting table: bread, cooked turkey, and carrot across the top row;
three wooden slabs across the middle row; bottom row empty. Mixed woods work.

Use cooked turkey on a supported block to place it, or hold use while aiming
into the air to eat it from your hand. Right-click placed meals when hungry.
